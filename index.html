THE IDEA

Remember one. Rebuild the rest.

A master key is combined with a service identifier using a deliberately slow key derivation step and a keyed cryptographic function. You can recreate the result later using the same tool version and settings.

A weak master key can still be guessed offline if an attacker knows one of your generated passwords. Use a long, unique master key and keep it private.

SECURITY MODEL

Local by design.
Not magic.

01

Nothing is sent to a server

The app uses the browser’s Web Crypto API. It does not use fetch/XHR, third-party scripts, analytics, cookies, or storage APIs.

02

Slow derivation, keyed output

PBKDF2-HMAC-SHA256 with 500,000 iterations derives a service-specific, non-exportable HMAC key using a fixed application salt and the SHA-256 hash of the canonical identifier. The HMAC signature is Base64URL-encoded and truncated to the requested length.

03

Identifiers matter

Identifiers are lowercased, trimmed, and stripped of everything except ASCII letters, digits, and hyphens. For example, github.com becomes githubcom. Use the same canonical identifier and settings each time.

04

Know the limits

A compromised device, browser extension, malicious browser update, or changed hosted code can expose secrets. A weak master key can be guessed offline. Copying also places the result on your system clipboard.

Compatibility warning

Keyform uses a compatible derivation profile: 500,000 PBKDF2 iterations, a service-derived salt, an HMAC-SHA256 signature, Base64URL encoding, and truncation. To recreate a password, use the same master key, canonical service identifier, total length, prefix, and suffix.
